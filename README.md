MAP MARKET

O Map Market é uma aplicação web desenvolvida para facilitar a experiência de compra dentro de supermercados. Ao escanear um QR Code disponível nos corredores da loja, o cliente acessa uma plataforma onde pode pesquisar produtos e visualizar informações importantes em tempo real, como disponibilidade, localização, preço e quantidade disponível.
O principal objetivo é reduzir o tempo de busca dos clientes, melhorar a experiência de compra e otimizar o atendimento dentro da loja.

Funcionalidades:
 
 -Pesquisa de produtos por nome
 -Exibição da localização do produto na loja
 -Consulta de preços
 -Visualização da quantidade disponível
 -Sugestão de produtos semelhantes
 -Interface responsiva para dispositivos móveis
 -Acesso rápido através de QR Codes espalhados pelo supermercado

Problema:
 
Em supermercados de médio e grande porte, muitos clientes têm dificuldade para localizar produtos específicos, causando perda de tempo e aumentando a necessidade de suporte dos funcionários. O Map Market resolve esse problema permitindo que o próprio cliente encontre rapidamente o que procura através do celular.

Como Funciona:

O cliente escaneia um QR Code disponível na loja.
A aplicação é aberta no navegador.
O cliente pesquisa o produto desejado.
O sistema exibe:

-Nome do produto
-Preço
-Disponibilidade
-Quantidade em estoque
-Corredor ou setor onde o item está localizado

Tecnologias Utilizadas:

-HTML
-CSS
-JavaScript

Exemplo de Uso:

Cliente escaneia QR Code
          ↓
Acessa a plataforma
          ↓
Pesquisa o produto
          ↓
Visualiza localização e disponibilidade
          ↓
Encontra o produto rapidamente

🚧 Status do Projeto
Projeto em desenvolvimento.

Atualmente o sistema possui apenas o Front-end desenvolvido utilizando HTML, CSS e JavaScript.
Funcionalidades futuras incluem integração com banco de dados, sistema de estoque em tempo real e painel administrativo para gerenciamento dos produtos.
